## 🚀 How to Use

### Generate Keywords
```bash
npx tsx scripts/generate-40k-keywords.ts
```

### Generate Sitemaps
```bash
npx tsx scripts/generate-sitemaps-40k.ts
```

### Build & Deploy
```bash
npm run build
vercel --prod
```

### Submit to Google Search Console
1. Go to https://search.google.com/search-console
2. Select property: www.humanifylab.com
3. Click "Sitemaps"
4. Submit these 10 URLs:
   - sitemap.xml
   - sitemaps/sitemap-index.xml
   - sitemaps/sitemap-1.xml through sitemap-8.xml
