### Scenario 1: Negative Press
**Response**:
1. Acknowledge immediately (within 2 hours)
2. Investigate thoroughly
3. Respond publicly with facts
4. Offer solution/compensation if warranted
5. Follow up to ensure resolution

### Scenario 2: Service Outage
**Response**:
1. Post status update immediately
2. Update every 30 minutes
3. Explain cause and solution
4. Offer compensation (extra credits)
5. Post-mortem report

**Response**:
1. Contain breach immediately
2. Notify affected users within 24 hours
3. Work with security experts
4. Implement fixes

1. Document everything
